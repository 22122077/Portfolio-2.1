Analysis of Precedent Portfolio

David Heckhoff

Visit Portfolio

I chose David Heckhoff’s portfolio for my case study because, overall, it feels very fun and playful while still demonstrating that he is a developer.

The desk scene immediately shows his profession as well as his personality. I like how it is the first thing that is visible when accessing the site as it is very attention grabbing and interesting. This helped me refine my own idea of using personal branding and handcrafted elements while keeping my software development role clear.

Project Presentation

The projects section and project detail pages really helped me have a better idea of how I can effectively display my own portfolio projects. I really like how each project is visual, clickable, and easy to scan.

Project Details

When clicking a specific project, a details page loads with a demo, technology tags, brief explanation, and links for live view and source code (where applicable). The demo being one of the first things you see for the project details is very good for quickly allowing the user to have an idea of what the project is and I plan on incorporating something similar in my site. I also will take inspiration from selective live links or source code where applicable but still have other content that allows the user to see what the project is even if they don’t visit those links (or if the project doesn’t include them).

Responsive Design

For responsiveness and mobile design, his visual identity carries over quite well with the project grid changing to accommodate different screen sizes gracefully. I like the layout for smaller screen as well. I will take inspiration from this for my own site responsiveness. Something I do wish was included in his mobile version is the navigation bar that is present in larger screen format. For my own site, I plan on keeping some sort of menu, possibly a top navigation bar or a hamburger menu, even when displayed on a smaller screen size.
